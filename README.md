# Next Phase Graphics

A layered image editor for Windows 10 and 11 that runs from a single exe.

**Website:** https://nrplyx.github.io/nextphasegraphics/
**Download:** [latest release](https://github.com/nrplyx/nextphasegraphics/releases/latest)

This repository holds the presentation page, served by GitHub Pages from the `main` branch. The program itself is attached to each release as a zip; unpack it anywhere and run `NextPhaseGraphics.exe`.
